## Síntese para revisão médica — 17/11/2026

Ersen: agulha 27G, entrada medial oblíqua, transdutor no tubérculo medial, até cinco pontos, três sessões a cada 21 dias; 3,6 mL de dextrose 15% mais 0,4 mL de lidocaína. Entre os que completaram, 20/26 tiveram resultado bom/excelente versus 4/24 no grupo de alongamento; o momento da taxa não ficou claro na extração e não se deve atribuí-lo a um prazo arbitrário.
