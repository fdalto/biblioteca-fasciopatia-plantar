# Convenções permanentes do projeto

- Preserve os códigos estáveis: A1 corticoide; A1.b infiltração por plano como subtipo técnico de A1; A2 dextrose hipertônica; A3 ácido hialurônico; A4 PRP; B1, B2, C1, C2 e D1 mantêm seus significados.
- A ordem de apresentação dos procedimentos A é sempre A1, A1.b, A2, A3, A4.
- Associe artigos à modalidade pela intervenção/substância descrita, não por um código legado isolado. Se a associação não puder ser determinada, registre conflito e não suponha.
- Propostas importadas do Work são sugestões revisáveis e nunca substituem automaticamente fichas médicas aprovadas.
- Não invente referências, resultados, protocolos, licenças ou procedência. Use “Não informado” ou “Não avaliado no texto completo” conforme aplicável.
- Preserve notas e conteúdo manual. Não sobrescreva silenciosamente informação confirmada; documente divergências.
- Mantenha uma ficha canônica por artigo e caminhos relativos para navegação Markdown.
- Preserve compatibilidade futura com MkDocs Material: prefira Markdown padrão, links relativos e imagens locais com procedência; não mantenha uma segunda versão do conteúdo para publicação.
- CSVs em UTF-8, com cabeçalhos documentados; alterações de modalidade devem ser revisáveis.
- Não contorne paywalls, DRM ou restrições de acesso. Baixe vídeos somente quando autorizado.
- Para importar: `python scripts/import_work.py`; para validar: `python scripts/validate_project.py`; para atualizar índices: `python scripts/build_index.py`.
